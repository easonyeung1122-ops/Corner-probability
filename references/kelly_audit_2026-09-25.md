# Kelly 仓位审计 — EPL 角球模型

**审计日期**：2026-09-25
**对象**：`epl-corner-probability` skill，7 条全场盘口线（O/U 7.5–13.5）
**方法**：Expanding-window walk-forward，训练集只用当期之前的数据，测试集为后 55%（1,039 场，6 折 × 173 场）
**样本**：2021-08-13 → 2026-08-24，1,889 场可用比赛（1,910 场原始数据）

---

## 一、结论

**当前应使用 0% Kelly，即不下注。**

不是"用少一点"，而是这个模型在样本外**不具备可测的预测能力**。任何大于零的 Kelly 分数，都是在把资金押在噪声上。当前 skill 默认的 35% Kelly 会把这一噪声放大 35%。

---

## 二、证据

### 2.1 数据完整性：通过

标签 `Target_L = (HC + AC > L)` 逐格核对 13,370 个单元格，**0 处不一致**。问题不在数据管线。

### 2.2 样本外判别力：≈ 随机

| 线 | 基准率 | RF AUC | Logit AUC | Brier Skill | 校准斜率 | ECE | RMS |
|---|---|---|---|---|---|---|---|
| 7.5 | 0.777 | 0.525 | 0.541 | −0.004 | 0.06 | 3.2% | 4.0% |
| 8.5 | 0.698 | 0.528 | **0.547** | −0.003 | 0.08 | 2.9% | 3.5% |
| 9.5 | 0.589 | 0.499 | 0.522 | −0.012 | −0.00 | 4.3% | 5.1% |
| 10.5 | 0.478 | **0.465** | 0.492 | −0.022 | −0.12 | 9.1% | 9.6% |
| 11.5 | 0.346 | 0.526 | 0.525 | −0.002 | 0.11 | 3.9% | 4.7% |
| 12.5 | 0.263 | 0.502 | 0.497 | −0.012 | 0.01 | 3.6% | 4.2% |
| 13.5 | 0.181 | 0.499 | 0.508 | −0.016 | −0.02 | 3.3% | 4.0% |

AUC 标准误 ≈ 0.019。**7 条线中 6 条落在 0.5 的 ±2σ 内**，唯一勉强显著的 8.5 线（0.547）也只有 2.4σ。

- **AUC = 0.50** → 模型排序与结果无关。
- **Brier Skill < 0** → 直接预测历史基准率比模型更准。
- **校准斜率 ≈ 0**（理论值应为 1）→ 模型概率的变动不含真实信息。

### 2.3 排序无信息（决定性证据）

按模型预测值分十档，看实际发生频率：

| 线 | 预测值区间 | 实际频率 |
|---|---|---|
| 9.5 | 0.49 → 0.68 | 0.62 → 0.54 → 0.62 → 0.55 → 0.63 → 0.58 → 0.62 → 0.58 → 0.53 → 0.62 |
| 10.5 | 0.39 → 0.57 | 0.48 → 0.58 → 0.45 → 0.51 → 0.50 → 0.60 → 0.37 → 0.44 → 0.37 → 0.49 |
| 12.5 | 0.19 → 0.36 | 0.27 → 0.28 → 0.27 → 0.23 → 0.28 → 0.21 → 0.30 → 0.21 → 0.33 → 0.25 |

模型把 9.5 线从 49% 抬到 68%，实际频率纹丝不动；10.5 线最高档（预测 57%）实际只有 49%，**反向**。
与市场无关，纯校准问题。

### 2.4 特征层面：源头上就没有信号

用独立实现（不依赖 skill 的特征构建器），仅取两队过去 10 场严格历史数据：

```
corr(总角球, 两队近10场角球获得之和)   = +0.023
corr(总角球, 两队近10场角球被获得之和) = +0.068
```

英超总角球：**均值 10.32，标准差 3.39**。球队级别的角球倾向几乎没有持续性——这是赛事本身的属性，不是模型的问题。用这个信号源，AUC 上限约 0.53。

|---|---|---|---|---|---|
| 8.5 | 3% | 270 | 17.6% | 0.719 | **+0.14%** |
| 8.5 | 5% | 120 | 23.2% | 0.733 | **+0.30%** |

模型声称有 edge 时，实际"捕获率"（真实 edge / 声称 edge）在 −0.88 到 +0.51 之间，中位数为负。
**以上还是按"市场价 = 基准率、零价差"测算的**。计入真实买卖价差后只会更差。

### 2.6 同场次集中度：7 条线是 1 个仓位

7 条线在同一场比赛上是**嵌套的**（>7.5 ⊃ >8.5 ⊃ … ⊃ >13.5），成对结果相关性 0.39–0.80。
它们是总角球的一个**支付阶梯**，不是 7 个独立下注。

按当前默认（35% Kelly、单笔上限 5%、声称 +6pp edge）逐线计算：

```
总仓位 27.6% 本金押在同一场比赛
P&L 标准差 22.9%
亏损概率 52%
```

按 35% Kelly 处理 7 条"独立"线的隐含信念是总仓位 27.6% 只承担单笔风险量级——实际风险是一整场比赛的结果。

## 三、如果 edge 被验证存在，用多少 Kelly

### 3.1 推导

二元合约在价格 `a`、胜率 `p` 下：

```
满 Kelly      f* = (p − a) / (1 − a)
倍数 λ 下的增长率   G(λ) ≈ λ(2 − λ) · G(1)
```

`λ = 2` 时增长归零，`λ > 2` 转负。所以超配的代价是非对称的。

参数不确定性下的最优倍数（预测收益 `μ̂ = μ + ε`，`Var(ε) = s²`，标的真实波动 `σ²`）：

```
λ* = σ² / (σ² + s²) = 1 / (1 + (s/σ)²)
```

`σ` = 你能真实捕获的 edge，`s` = 你估计 edge 的误差。
实测 `s ≈ 3.5%–5.0%`（上表 RMS）。若合理预期可捕获 edge `σ = 3%–5%`，则 `s/σ ≈ 1`，得 `λ* ≈ 0.5`；若只有 `σ = 2%`，则 `λ* ≈ 0.25`。

### 3.2 建议参数

| 参数 | 现值 | 建议 | 依据 |
|---|---|---|---|
| Kelly 系数 | 0.35 | **0.25** | 取 3.1 推导的下沿，对模型误差留余量 |
| 单笔上限 | 5% | 5%（保留） | — |
| **同场次总仓位上限** | 无 | **6%** | 7 条线是一个事件；约等于单笔上限的 1.2 倍 |
| min_edge | 3% | **5%–6%** | 模型自身 OOS 误差 RMS 3.5–5pp，3% 的 "edge" 全在噪声带内 |
| 前置门禁 | 无 | **OOS AUC ≥ 0.55 且 Brier Skill > 0** | 见 4.1 |

### 3.3 何时才允许非零仓位

必须同时满足：

1. 全部 7 条线的 walk-forward OOS AUC ≥ 0.55（当前 6/7 条在 0.50 附近）；
2. 校准斜率在 0.7–1.3 之间（当前 ≈ 0）；
3. 分档可靠性单调（当前 10.5 线反向）；
4. 声称 edge 的实测捕获率 ≥ 0.5，样本 ≥ 200 注。

## 四、修复路径

### 4.1 立即：加样本外验证门禁

当前 skill 只在 `train_models.py` 打印 **in-sample accuracy**（第 108–109 行），这是本问题长期隐形的原因。必须补一个 walk-forward 验证步骤，把 OOS AUC / Brier Skill / 校准斜率作为下注的前置条件。

### 4.2 中期：换信息源

现有 19 个特征全部来自球队近期角球/射门统计，与总角球相关性仅 0.02–0.07。要做出可用模型，需要**与角球生成机制直接相关**且市场定价不足的变量：

- **主裁判**：不同裁判的角球判罚倾向差异显著，且是可查的公开数据；
- **教练/阵型**：进攻宽度、传中频率；
- **天气与场地**：风速、降雨显著影响传中与解围出界；
- **市场隐含概率本身**：作为特征而非对手。

### 4.3 更现实：转向市场自洽性套利

模型里已有的 `market_monotonicity()` 检查指出了一条**零预测需求**的路径。

由于 `{T > 9.5} ⊂ {T > 8.5}`，必须恒有 `P(>8.5) ≥ P(>9.5)`。若市场报价违反该关系：

```
买入 Under 9.5  +  买入 Over 8.5
成本 = ask(Under 9.5) + ask(Over 8.5)
```
无论总角球落在何处，该组合至少支付 1。**成本 < 1 即为无风险套利**，不需要任何预测能力。

这比方向性下注更适合当前工具的能力边界：套利只要求正确的逻辑，不要求正确的概率。

## 五、方法学说明与局限

1. **无历史盘口**：Polymarket 角球市场 2026 年才上线，历史价格不可得。2.5 节的"捕获率"以基准率作为零信息市场价代理。**但 2.2 / 2.3 节的校准结论不依赖任何市场假设**——那是"模型说 66%，实际 56%"的纯统计事实，是本次审计的决定性证据。
2. **测试样本量**：1,039 场样本外比赛，每线 120–409 注。足以区分 AUC 0.50 与 0.55，不足以精确估计 0.53 与 0.55 的差别。
3. **特征文件复用**：回测使用 skill 预计算的 `cache/features.csv`。若该文件含前视偏差，本次测试是**偏宽松**的——即便如此仍无信号，故负向结论稳健。
4. **模型可改**：本次审计未穷举特征工程与超参数空间。结论是"当前配置 + 当前特征集"下无样本外 edge，不等于角球市场不可战胜。
